# Hamkor tashkilotlar logotiplari

Bu papka **bo'sh** va shunday qolishi kerak, toki institut hamkorlar ro'yxatini
bermaguncha.

Hamkor tashkilot logotipi uning **savdo belgisi** hisoblanadi. Internetdan izlab
topilgan yoki o'zimiz tanlagan logotip qo'yilmaydi — faqat institut bilan
haqiqatan hamkorlik qiladigan tashkilotlar, institut taqdim etgan ro'yxat bo'yicha.

## Qanday qo'shiladi

1. Logotip faylini shu papkaga qo'ying (`nom.png` yoki `nom.svg`).
2. Admin panel → Hamkorlar → Yangi qo'shish.
3. "Logotip manzili" maydoniga `/images/partners/nom.png` deb yozing.

Ro'yxat bo'sh bo'lsa, bosh sahifadagi hamkorlar bo'limi **umuman ko'rinmaydi**.

Fayl yuklash imkoniyati R2 orqali keyinroq qo'shiladi (CLAUDE.md, 5-muammo).
